Crossover a taste check for AI agents, built on Qloo

Same model. Same question.
One of them can check its taste.

Name three films and get music, or three artists and get films. The same LLM answers twice. Once from memory. Once as an agent that asks Qloo's taste graph, checks its own ideas against it, and may only recommend what Qloo has verified. Pick the list you prefer without knowing which is which, then see the numbers.

          How to read this
          
          
            
            
          • One variable. Both sides use the same model and get the same inputs. The only difference is that the agent can call Qloo. If one side had to fall back to a different model because of rate limits, the model names above will differ and you should read the result with that in mind.
            • 
            
          • The agent leads on taste fit by design. Taste fit is Qloo's own score, and the agent chooses using it. That row shows how far an unaided LLM lands from what the graph supports. It is not an independent verdict.
            • 
            
          • The independent evidence is the blind vote. People choosing between unlabelled lists is the one measure here that neither Qloo nor an LLM controls.
            • 
            
          • Nothing is estimated. A pick counts only when its name matches a Qloo catalog entry exactly (for films, the release year too) and Qloo returns a score. Otherwise it is marked "not measured" and left out of every number.
