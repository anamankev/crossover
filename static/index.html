Name three films and get music, or three artists and get films. One answer comes from Qloo's taste graph. The other comes from an LLM working from memory. Then we measure the LLM's picks against the graph and show you the numbers.

      How this was measured

      • Same question, both sides. The LLM gets the same inputs, as matched in Qloo, and is asked for the same number of picks. It is not told to be mainstream or obscure. The exact prompt is below.
      • Taste fit is Qloo's own score. We look each LLM pick up in Qloo's catalog and ask Qloo how well it fits your inputs. Qloo's list is ranked by that score, so Qloo leads on it by construction. The useful reading is the gap, and which LLM picks the graph agrees with.
      • Nothing is estimated. A pick only counts when its name matches a catalog entry exactly (for films, the release year too) and Qloo returns a score. Otherwise it is shown as "not measured" and left out of every number.
      • What this cannot tell you. Whether you would actually enjoy a pick. That needs people, not a score.
